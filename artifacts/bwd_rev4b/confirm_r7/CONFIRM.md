## New in-scope findings

### BWDR4BR7-F01

**MINOR · The summary join accepts a wrong scalar type.** A verdict exporter routes a summary counter through a float-valued record and serializes it back into the verdict. The real covered summary has integer probes=40. Changing only the verdict to probes=40.0 passed the full preflight call. A verdict with probes=41 was refused. The manifest still matched the independent seal and the covered summary digest was unchanged. Compare JSON values recursively with exact scalar types, or compare canonical JSON serializations with nonfinite values refused. [Source](../../../../tensor_fork_bwd_wt_r4b/scripts/bwd_r4b_verify.py#L376) · [CPU witness](commands/20-probes.log)

### BWDR4BR7-F02

**MINOR · A failed merge retry can leave the prior green result eligible.** The operator reruns merge at the fixed staging root after a completed run and a later launcher preflights that same root. On a copy of the complete lead bundle, the real merge hit FileExistsError and wrote a red sidecar. The consumer still accepted the old canonical verdict and manifest, whose bytes and independent seal were unchanged. The retry itself was red. Publish each attempt under its own identity and make preflight consume the explicitly selected passing attempt. If the fixed root remains canonical, make preflight reject a red retry marker for the selected attempt. ### BWDR4BR7-F03

**MINOR · Sampler clock and period headers are only type-checked.** A sampler or exporter uses a stale clock label or a sign error in the configured period when writing the record header. Replaying the lead checkpoint rows with CLOCK_REALTIME or period -0.002 separately returned valid=true, zero problems and 1,463 PID-valid samples. Changing only the PID was refused. The producer emits CLOCK_MONOTONIC and the worker supplies its own configured period. Require CLOCK_MONOTONIC and a finite, positive period equal to the period the worker supplied. [Source 1](../../../../tensor_fork_bwd_wt_r4b/scripts/bwd_r4b_gpu_r7.py#L74) · [Source 2](../../../../tensor_fork_bwd_wt_r4b/scripts/bwd_r4b_gpu_r7.py#L96) · [Source 3](../../../../tensor_fork_bwd_wt_r4b/scripts/bwd_r4b_gpu_r7.py#L161) · [CPU witness](commands/20-probes.log)

**MINOR · Missing JUnit totals are silently inferred as zero.** An XML report exporter drops zero-valued suite attributes while copying a completed report. The Ant/JUnit XML format (circa 2001) and pytest’s JUnit exporter supply the suite totals and test IDs. Requiring the four emitted totals here follows the existing pytest writer.
