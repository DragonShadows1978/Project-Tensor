Both the preflight and full worker calls returned successfully with every manifest-covered file unchanged. Require the exact verdict schema and literal passing flag. Join the wave digest to the live manifest and the summary to the manifest-covered summary file. ### BWDR4BR6-F02 · MAJOR · The reference producer can pass a bundle the seal rejects

Use strict shared loaders for reference intermediates and apply the registered manifest and bundle checks before emitting a passing merge result. ### BWDR4BR6-F03 · MAJOR · G5 accepts records with invalid PID or sample structure

On replay of the retained checkpoint trace, coverage accepted PID 1249161 in place of 1249160, accepted omission of the PID header, and counted a timestamp-only row as PID-valid. The row’s last item doubles as the memory payload, so a missing payload can become a floating-point timestamp. Require the expected worker PID and exactly three fields per sample with finite, ordered query times and a nonnegative integer byte count or explicit null. Reject a malformed row and keep null readings outside the coverage count. - NIST FIPS 180-4 (2015) supplies SHA-256. Dolstra’s Nix (2006) is prior art for independent input pins. The proposed producer check reuses the existing registration and r6 consumer for this capture.
- Bray’s RFC 8259 (2017), section 4, specifies unique JSON object names as interoperability guidance. The proposed strict producer reads reuse the existing parser and the verdict schema follows the R4b writer.
- NVIDIA NVML and CUDA documentation supplies process-query and allocation semantics. DLPack (dmlc, 2017 onward) supplies tensor address and device metadata. The proposed PID binding and current-device restoration apply those interfaces to this harness.
- No specific prior art known to me for the exact receipt joins, JUnit census comparison and timeout probes. The proposed census reuses IDs from the sealed R4b test suite, and the timeout change uses Python’s existing cleanup and decode facilities.
